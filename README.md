# ColorJoy

A mobile-friendly coloring studio for kids and adults. Color by tapping shapes or drawing freely, use the palette and eraser, undo and redo, save projects locally, and export artwork as PNG.

## Run locally
Open `index.html` in a modern browser. For install/PWA features and offline caching, serve the folder over HTTPS (GitHub Pages or Cloudflare Pages).

## Deploy
This is a static site. Connect this repository to Cloudflare Pages with no build command and `/` as the output directory, or enable GitHub Pages from the `main` branch and root folder.
